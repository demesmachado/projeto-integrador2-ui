Saúde Digital

Cuidado conectado entre pacientes e profissionais de saúde.

Uma plataforma única para hospitais, planos de saúde e organizações acompanharem consultas, evolução clínica e bem-estar dos pacientes — com agenda integrada e recomendações personalizadas.

  • 🗓️ Agenda de consultas com solicitação pelo paciente
  • 🩺 Registro de peso, IMC, pressão, glicemia, sono e mais
  • 🔔 Notificações de medicamentos e bem-estar
  • 🔒 Dados sensíveis protegidos com criptografia

Versão 1.0 — protótipo funcional, dados salvos localmente no seu navegador.

Termos de uso

Este é um protótipo (1ª versão) do sistema Saúde Digital, executado inteiramente no seu navegador.

  • Os dados informados (cadastros, consultas, evolução, agenda) são armazenados localmente, no LocalStorage do seu navegador — nesta versão nada é enviado a um servidor externo.
  • Dados sensíveis de pacientes, consultas e evolução são armazenados de forma criptografada; senhas de acesso nunca são salvas em texto puro, apenas como hash.
  • No momento não estamos utilizando cookies, para melhor performance do sistema. O uso de cookies está previsto para ser implementado na 2ª versão da aplicação web.
  • Por ser uma versão de demonstração, ao limpar os dados do navegador todas as informações cadastradas serão perdidas.
